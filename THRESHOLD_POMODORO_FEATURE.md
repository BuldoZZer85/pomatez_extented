# Пороговые значения Помодоро (Threshold Pomodoro Feature)

## Описание

Эта функция расширяет классическую технику Помодоро, добавляя **пороговые значения** с минимальным и максимальным временем для каждой сессии.

Вместо жестко зафиксированных 25 минут фокуса и 5 минут отдыха, теперь вы можете установить:
- **Минимальное время** (25 мин) - получите **зеленое уведомление** при достижении
- **Максимальное время** (50 мин) - получите **красное уведомление** с рекомендацией завершить сессию

## Основные возможности

### 🎯 Гибкие настройки времени
- **Фокус**: от 25 мин (мин) до 50 мин (макс)
- **Короткий перерыв**: от 5 мин (мин) до 15 мин (макс)
- **Длинный перерыв**: от 15 мин (мин) до 30 мин (макс)

### 🔔 Умные уведомления
- ✅ **Зеленое уведомление**: минимум достигнут - можно продолжать или завершить
- ⚠️ **Красное уведомление**: максимум достигнут - рекомендуется завершить сессию

### 📈 Визуальный индикатор прогресса
- **Желтый цвет**: еще не достигнут минимум
- **Зеленый цвет**: между минимумом и максимумом (оптимальная зона)
- **Красный цвет**: превышен максимум

## Архитектура

### Ключевые файлы

#### Общие типы и утилиты (`app/shareables/src/`)
- `types/ThresholdTimer.ts` - типы TypeScript для конфигурации и состояния
- `utils/thresholdTimer.ts` - утилиты для работы с порогами
- `index.ts` - обновленные IPC константы

#### React компоненты (`app/renderer/src/`)
- `components/ThresholdSettings.tsx` - компонент настроек
- `components/ThresholdProgressIndicator.tsx` - индикатор прогресса
- `hooks/useThresholdTimer.ts` - React хук для управления состоянием
- `styles/threshold-components.css` - стили CSS

### IPC коммуникация

Новые каналы IPC:
- `SET_THRESHOLD_CONFIG` - сохранение конфигурации
- `GET_THRESHOLD_CONFIG` - получение конфигурации
- `THRESHOLD_NOTIFICATION` - отправка уведомления
- `TIMER_THRESHOLD_UPDATE` - обновление состояния таймера
- `RESET_THRESHOLD_STATE` - сброс состояния порогов

## Как использовать

### 1. Открыть настройки
Найдите кнопку "Настройки порогов" в меню приложения.

### 2. Настроить временные пороги
Для каждого типа сессии (фокус, короткий и длинный перерыв) установите:
- **Минимум** - время, после которого можно завершить сессию
- **Максимум** - время, после которого рекомендуется завершить

### 3. Запустить сессию
Начните сессию Помодоро. Приложение будет:
- Отображать прогресс с цветовыми индикаторами
- Показывать оставшееся время до порогов
- Отправлять уведомления при достижении порогов

## Пример работы

### Сессия фокуса (25-50 мин)

1. **0-25 мин**: желтый индикатор, "До минимума: X мин"
2. **25 мин**: ✅ **Зеленое уведомление** - "Минимум достигнут!"
3. **25-50 мин**: зеленый индикатор, "До максимума: X мин"
4. **50 мин**: ⚠️ **Красное уведомление** - "Максимум достигнут! Рекомендуется завершить."
5. **>50 мин**: красный индикатор, "Максимум превышен!"

### Перерыв (5-15 мин)

1. **0-5 мин**: желтый индикатор
2. **5 мин**: ✅ **Зеленое уведомление** - минимальный отдых получен
3. **5-15 мин**: зеленый индикатор
4. **15 мин**: ⚠️ **Красное уведомление** - пора возвращаться к работе

## Преимущества

✅ **Гибкость**: адаптируйте время под свои потребности и тип задач
✅ **Умные напоминания**: не пропустите оптимальное время для перерыва
✅ **Продуктивность**: работайте длиннее, когда находитесь в потоке
✅ **Визуальная обратная связь**: всегда знайте, на каком этапе находитесь

## Тестирование

Для тестирования функциональности:

1. Клонируйте репозиторий и перейдите на ветку `feature/threshold-pomodoro`
2. Установите зависимости: `yarn install`
3. Запустите приложение: `yarn dev:app`
4. Откройте настройки пороговых значений
5. Установите малые значения для быстрого тестирования (например, 1-3 мин)
6. Запустите сессию и проверьте уведомления
